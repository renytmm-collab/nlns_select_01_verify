# 冻结分类器确认实验 v1

2026-10-10。新确认协议；不修改或绕过 point-objective-v2。

主模型只引用旧开发集选出的 lens_classifier：L2=.1，改善事件阈值0，参数与预处理不重拟合。
简单规则固定 contact_edges。其他旧模型仅为次要对照，测试后不可替换主模型。
两项主比较为分类器减原生随机期望、分类器减接触边规则。
WR减AR、分类器减AR以及50/200分层仅为探索性次要分析。

部署固定单状态batch1。标注采用同一状态、同一动作的16个独立重复的同质batch16；
候选之间和状态之间不混批，每条标签必须自然输入长度等于补齐长度。
前提是已有1024次同质校准通过，原异质batch16不一致仍保留，不能把本协议解释为修复了该问题。
校准只覆盖旧64组动作及固定种子；新状态上的同质/单状态一致性仍依赖这一外推。
不修改actor、Repair、checkpoint；软件不把采样校准当成所有输入上的数学证明。

默认192个全新ALTR_100实例，root_seed=2026101001，语义ID从旧开发实例数起顺序分配。
新root seed作用于实例、状态演化、候选、test_A/B、平局和bootstrap。
复用原语义随机流算法（含原Point算法版本），新协议身份独立记录。
历史排重为已知历史清单加旧开发catalog，新样本内部亦排重；不能宣称全历史排重。
初解沿用原实现，用原生随机Point/固定Repair迭代200次，不恶化才接受，在50/200步取快照。
Point仍16原生槽位，每个删除20客户；重复集合共享标签但保留槽位权重。
12特征固定。所有模型分数、最高分平局、一次随机选择在任何测试A/B标签之前冻结。
A32只用于冻结付费带噪声参照（精确平局最小ID），不训练或选模；之后独立B128主评价。
每rollout先z=max(y,0)再平均；最高分平局槽位均匀选择的期望为主。
重复→槽位平局期望→50/200等权→实例等权。独立统计单位只有实例。

样本量针对较大优势复现：null=0pp，alternative=.05pp，每比较正态近似80%功效。
两个主比较alpha=.05/2。规划SD取旧独立V实例差值SD及实例bootstrap SD的80%上分位较大者。
check重新计算建议N（至少64、向上16倍），192不得低于建议值；不足则在生成新实例前阻断。
192不是对.01pp优势有充分功效的保证，也不是证明真实优势>.01pp。
继续条件：两个主比较均值>=.01pp、校正单侧配对t下界>0且各自95%实例bootstrap下界>0。
开发与测试均要求单状态E[z]/完整路径时间代理对两个基线>=1.05。
仅使用旧benchmark的batch1稳态时间，异质批量结果不用作部署时间。
该时间代理代表旧开发状态，不是新测试延迟实测，也不是完整搜索收益。
